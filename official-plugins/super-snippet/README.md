# 超级文本片段 (Super Snippet)

> 快速插入预定义文本片段到任意应用

## 功能特性

- 📝 **片段管理** - 创建、编辑、删除、启用/禁用文本片段
- 📁 **分组管理** - 支持多分组，便于组织大量片段
- 🔍 **全局搜索集成** - 片段可通过关键字在 UniHub 全局搜索中触发
- ⚡ **智能粘贴** - 将文本插入到上一个活动窗口的光标位置
- 🔄 **占位符系统** - 支持动态变量进行内容替换

## 支持的占位符

| 占位符 | 说明 |
|--------|------|
| `{date}` | 当前日期 |
| `{time}` | 当前时间 |
| `{datetime}` | 日期时间 |
| `{timestamp}` | 时间戳 |
| `{clipboard}` | 剪贴板内容 |
| `{random}` | 随机字符串 |
| `{uuid}` | UUID |

## 粘贴方式

- **模拟快捷键** - 常规粘贴 (Ctrl+V)，兼容性最好
- **键盘输入** - 逐字符输入，适用于不支持粘贴的场景
- **终端执行** - 在终端中执行命令

## 后置动作

- **还原剪贴板** - 粘贴后恢复原始剪贴板内容
- **保留剪贴板** - 保持当前内容在剪贴板
- **仅复制** - 只复制不粘贴
- **按下回车** - 粘贴后自动按回车

## 开发

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建
pnpm build

# 打包
pnpm package
```
